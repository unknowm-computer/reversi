# 잔나비와 베짱이 — 리버시 클럽

Vue 3 + TypeScript로 만든 웹 리버시 게임입니다. 느긋한 베짱이가 되어 잔나비 AI와 겨루거나, 한 기기 또는 온라인 방에서 친구와 플레이할 수 있습니다.

## 실행

Node.js **22.12 이상**과 npm이 필요합니다. 개발 및 검증 환경은 Node.js 22.23.1입니다.

```sh
npm ci
npm run dev
```

브라우저에서 **http://localhost:5188**에 접속합니다. 프론트엔드와 온라인 서버를 함께 실행하며, 서버 포트는 `3001`입니다. 다른 앱과의 충돌을 피하려고 프론트엔드 포트를 `5188`로 고정했습니다.

같은 Wi-Fi의 다른 기기에서는 Vite가 출력하는 Network 주소(`http://내컴퓨터IP:5188`)로 접속할 수 있습니다. 프론트엔드가 `/socket.io` 요청을 서버에 전달하므로 두 플레이어는 같은 프론트엔드 주소를 사용하면 됩니다.

## 조작과 모드

- **혼자 놀기:** 사용자는 베짱이/흑, AI는 잔나비/백입니다. 무르기는 사용자가 마지막으로 착수하기 직전까지 되돌립니다.
- **함께 놀기:** 한 기기에서 번갈아 플레이합니다. 무르기는 자기 차례에 내 직전 수와 이후 상대의 수를 함께 되돌리며 내 횟수를 사용합니다. 인당 1회/3회/무제한/사용 안 함을 선택합니다.
- **온라인:** 방을 만들고 6자리 코드를 공유합니다. 둘 다 준비를 누르면 시작합니다. 준비 전에는 캐릭터를 서로 바꿀 수 있고, 중복 캐릭터는 허용하지 않습니다.
- 표시된 합법 수를 클릭/탭하거나, 보드에서 방향키로 이동하고 Enter/Space로 착수합니다.
- **조이패드:** 대국 시작 후 패드의 버튼을 한 번 눌렀다 떼면 연결됩니다. 십자키/왼쪽 스틱으로 칸을 이동하고, 아래쪽 버튼(Xbox A / PlayStation ×)으로 착수합니다. 선택 칸은 노란 테두리로 표시하며 모든 대전 모드에서 사용할 수 있습니다. 설정·무르기·팝업은 기존 마우스/터치/키보드로 조작합니다.
- 브라우저가 `standard`로 인식하는 패드와 Gamepad API가 필요합니다. `localhost` 또는 HTTPS에서 사용하세요. AI 차례·연출·팝업·비활성 창에서는 패드 입력을 막고, 복귀 시 버튼과 스틱을 놓은 뒤 다시 조작합니다.
- 모서리에서 4개 이하를 뒤집으면 플레이어 카드에서 잔나비는 사악하게 웃고 웃음 효과음을, 베짱이는 웃는 표정과 휘파람 효과음을 약 2.6초간 보여줍니다. 소리는 Web Audio 합성이며 사운드 설정을 따릅니다. 모서리 여부와 관계없이 한 수에 5개 이상 뒤집으면 웃음·휘파람 반응보다 타격 연출이 우선하며 약 0.7초 타격 연출 후 돌이 뒤집힙니다. 싱글/로컬은 연출 후 다음 턴 시간을 시작하며 온라인은 서버 시간을 따릅니다.
- 턴 시간은 제한 없음/30초/60초 중 선택합니다. 모든 모드의 기본값은 30초입니다. 0초가 되면 삑 효과음을 한 번 재생하고 **봐준다 / 게임 종료**를 선택합니다. 혼자 놀기는 사용자, 함께 놀기·온라인은 상대가 선택하며, 선택 중에는 착수와 타이머가 멈춥니다. 봐주면 꿀밤 후 보드·점수·차례를 유지하고 시간을 새로 받으며, 게임 종료를 고르면 상대의 승리입니다.
- 합법 수가 없으면 자동 패스하며, 양쪽 모두 착수할 수 없으면 빈칸이 남아 있어도 종료합니다.
- 일반 종료 후에는 결과 화면에서 마지막 수를 무를 수 있습니다. 기권·시간 초과 및 온라인에서는 무를 수 없습니다.
- 로컬/싱글은 다른 탭으로 이동하면 시간과 AI가 멈춥니다. 온라인은 서버 시간이 계속 흐르고 연결 해제 후 30초의 복귀 유예를 제공합니다.
- 온라인 새로고침은 같은 탭의 세션으로 복구됩니다. 재대결은 양쪽 동의가 필요합니다. 방 나가기는 방 전체를 종료합니다.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | Vite + 온라인 서버 동시 실행 |
| `npm run dev:web` | 프론트엔드만 실행 |
| `npm run dev:server` | 온라인 서버만 실행 |
| `npm run typecheck` | 프론트엔드 및 서버 타입 검사 |
| `npm test` | 규칙·AI·무르기·타이머·온라인 통합 테스트 |
| `npm run test:watch` | 테스트 감시 모드 |
| `npm run build` | 타입 검사 후 프론트엔드와 서버 빌드 |
| `npm start` | 빌드 결과와 Socket.IO를 단일 서버로 제공 |
| `npm run preview` | 프론트엔드 빌드 미리보기; 온라인 서버는 포함하지 않음 |

## 빌드한 게임 실행

```sh
npm run build
npm start
```

**http://localhost:3001**에서 프론트엔드와 온라인 기능을 함께 제공합니다. 배포 시에는 WebSocket을 지원하는 리버스 프록시와 HTTPS를 연결합니다. 외부 호스팅 배포는 아직 수행하지 않았습니다.

환경 변수는 필수가 아닙니다.

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `PORT` | `3001` | Node.js 서버 포트. 개발 서버에서 변경하면 `vite.config.ts` 프록시도 맞춰야 합니다. |
| `VITE_SERVER_URL` | 현재 origin | 별도 Socket.IO 주소가 필요한 경우 사용. 일반 실행은 같은 origin과 프록시를 권장합니다. |

방과 대국은 단일 서버의 메모리에 보관합니다. 서버를 재시작하면 사라집니다. 다중 서버 배포, 계정, 저장된 대전 기록, 랭킹은 구현하지 않았습니다.

## 구현 구조

```text
shared/game/         순수 규칙 엔진, 게임 타입, AI 탐색
shared/protocol.ts   온라인 메시지 타입과 Zod 입력 검증
src/stores/          Pinia 게임 상태와 무르기 이력
src/composables/     진행 제어, 타이머, 오디오, 리액션, 온라인 연결
src/workers/         AI Web Worker
src/components/     시작 화면, 보드, 플레이어, 대기실, 결과, 공통 UI
src/styles/          글로벌 스타일과 디자인 토큰
server/              서버 권한 판정, 방·세션·시간 관리, 정적 파일 제공
tests/               규칙/스토어/수명 주기/네트워크 테스트
```

캐릭터는 직접 작성한 SVG와 CSS 애니메이션이며, BGM 3종 및 SFX는 Web Audio로 합성합니다. 외부 이미지·음원 다운로드나 API 키가 필요하지 않습니다. 사운드는 첫 사용자 입력 이후 활성화됩니다.

## 검증과 현재 범위

- Chrome에서 싱글 대국 종료, AI 응답 전후 무르기, 키보드 착수, 로컬 60수 대국 종료를 확인했습니다.
- 두 Chrome 탭에서 온라인 입장·캐릭터 교환·착수 동기화·새로고침 복귀·기권·재대결·방 종료를 확인했습니다.
- Chrome의 390px 시작 화면, 320px 게임 화면에서 가로 넘침 없이 표시되는 것을 확인했습니다.
- 조이패드 연결/해제, 스틱 데드존, 방향 반복, 중복 착수 방지, 입력 잠금과 보드 연동을 가상 패드 자동 테스트로 확인했습니다. 실물 패드의 USB/Bluetooth 연결은 아직 검증하지 않았습니다.
- 실제 iOS Safari의 터치·오디오와 외부 네트워크 환경은 별도 검증이 필요합니다.
- 캐릭터와 엔딩은 SVG/CSS로 만든 초기 연출입니다. 기획의 세밀한 표정·큰절·상호작용 및 녹음된 캐릭터 음성은 추가 아트 작업 대상으로 남겨두었습니다.
