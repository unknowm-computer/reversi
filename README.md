# 잔나비와 베짱이 — 보드게임 클럽

Vue 3 + TypeScript로 만든 리버시·오목·체스·장기 게임입니다. 게임과 캐릭터를 고른 뒤 AI와 겨루거나, 한 기기 또는 온라인 방에서 친구와 플레이할 수 있습니다. 네 게임은 같은 프로필·타이머·무르기·힌트·재대결 구성을 사용합니다.

## 실행

Node.js **22.12 이상**과 npm이 필요합니다. 개발 및 검증 환경은 Node.js 22.23.1입니다.

```sh
npm ci
npm run dev
```

브라우저에서 **http://localhost:5188**에 접속합니다. 프론트엔드와 온라인 서버를 함께 실행하며, 서버 포트는 `3001`입니다. 다른 앱과의 충돌을 피하려고 프론트엔드 포트를 `5188`로 고정했습니다.

같은 Wi-Fi의 다른 기기에서는 Vite가 출력하는 Network 주소(`http://내컴퓨터IP:5188`)로 접속할 수 있습니다. 프론트엔드가 `/socket.io` 요청을 서버에 전달하므로 두 플레이어는 같은 프론트엔드 주소를 사용하면 됩니다.

## 조작과 모드

- **게임 선택:** 시작 화면에서 리버시·오목·체스·장기를 고릅니다. 게임 방법은 선택한 게임의 설명으로 바뀌며, 온라인 입장은 방장이 선택한 게임을 따릅니다.
- **대국 준비:** 첫 화면에서는 모드·게임·캐릭터만 선택합니다. 시작 버튼을 누르면 게임판 위 설정 팝업에서 난이도·제한 시간·무르기 횟수·장기 포진을 정하고 대국을 시작합니다. 팝업을 확인하기 전에는 착수와 타이머가 정지하며, 취소하면 첫 화면으로 돌아갑니다. 온라인은 방을 만들기 전에 설정하고, 입장하는 친구는 방의 설정을 따릅니다.
- **설정 기억:** 첫 화면과 설정 팝업에서 고른 게임·캐릭터·대전 모드·난이도·장기 포진·무르기 횟수와 모드별 제한 시간을 브라우저의 로컬 스토리지에 저장합니다. 새로고침하거나 처음으로 돌아와도 선택을 유지합니다.
- **리버시:** 8×8 판에서 상대 돌을 사이에 끼워 뒤집습니다. 양쪽 모두 놓을 곳이 없으면 돌이 더 많은 쪽이 승리합니다.
- **오목:** 빈 15×15 판에서 흑부터 교차점에 번갈아 놓습니다. 흑·백 모두 **3-3·4-4·장목(6개 이상)** 금수를 적용하고, 정확히 5개를 연결하면 승리합니다. 열린 3은 한 수를 더 두어 양끝에서 정확히 5개를 완성할 수 있는 연속 4로 만들 수 있는 형태이며, 중간이 한 칸 띄어진 형태도 포함합니다. 한 수로 열린 3 두 개 또는 다음 수에 5개를 완성할 수 있는 4 두 개를 동시에 만들 수 없습니다. 금수 자리는 붉은 ×로 표시하고 AI·힌트에서도 제외합니다. 어느 방향이든 장목이 생기는 수는 금수이며, 장목 없이 정확히 5개를 완성하는 승리 수는 3-3·4-4보다 우선합니다. 승리한 줄은 금색으로 표시합니다. 승자 없이 판이 꽉 차면 무승부이며, 프로필의 착수 횟수는 승점이 아닙니다. 빈자리가 남아도 현재 차례의 플레이어가 금수로 둘 곳이 없으면 패배하며, 양쪽 모두 둘 곳이 없으면 무승부로 끝납니다.
- **체스:** 8×8 판에서 백이 선공입니다. 기물을 선택한 뒤 이동할 칸을 선택합니다. 체크메이트로 승리하며 캐슬링·앙파상·4종 폰 승격을 지원합니다. 스테일메이트·기물 부족·동일 국면 3회·50수 규칙은 자동 무승부로 처리합니다. 3회 반복과 50수에서 별도 무승부 청구를 받지 않는 친선 진행 방식입니다.
- **장기:** 9×10 교차점에서 초(파랑)가 선공입니다. 양쪽의 상·마 포진 4종을 설정하며, 온라인 포진은 방장의 설정을 사용합니다. 궁성·마와 상의 멱·포의 다리 및 포 예외·졸의 궁성 이동·장군과 외통수를 판정합니다. 장군이 아닐 때 한 수 쉴 수 있습니다. 빅장에는 해소하는 수 또는 빅장 수락으로 응수하며, 수락·연속 두 번 쉼·동일 국면 3회는 무승부입니다. 대회 점수제나 덤을 적용하지 않는 친선 규칙입니다.
- **혼자 놀기:** 사용자가 잔나비·베짱이 중 원하는 캐릭터를 골라 선공으로 시작하고, AI는 다른 캐릭터로 후공을 맡습니다. 난이도는 1단계 입문부터 5단계 매우 어려움까지 선택하며 기본은 3단계 보통입니다. 무르기는 사용자가 마지막으로 착수하기 직전까지 되돌립니다.
- **다시하기:** 결과창의 한 판 더 하기 또는 상단의 다시하기를 누르면 이전 설정이 담긴 팝업을 엽니다. 난이도·시간·무르기·장기 포진을 확인하거나 바꾼 뒤 새 판을 시작합니다. 온라인은 양쪽이 동의하면 같은 방에서 방장이 설정을 확정하고, 상대가 확인해 준비 완료를 누르면 시작합니다. 설정 중에는 시간이 흐르지 않습니다.
- **힌트:** 혼자 놀기에서 내 차례에 횟수 제한 없이 사용할 수 있습니다. 추천 칸을 금색 전구로 표시하며 직접 착수합니다. 체스·장기는 출발 기물과 도착지를 함께 강조하며, 장기는 한 수 쉼을 추천할 수도 있습니다. AI 난이도와 제한 시간은 그대로 유지됩니다.
- **함께 놀기:** 한 기기에서 번갈아 플레이합니다. 무르기는 자기 차례에 내 직전 수와 이후 상대의 수를 함께 되돌리며 내 횟수를 사용합니다. 인당 1회/3회/무제한/사용 안 함을 선택합니다.
- **온라인:** 방을 만들고 6자리 코드를 공유합니다. 둘 다 준비를 누르면 시작합니다. 준비 전에는 캐릭터를 서로 바꿀 수 있고, 중복 캐릭터는 허용하지 않습니다.
- 리버시는 표시된 합법 수를, 오목은 금수 표시가 없는 빈 교차점을 클릭/탭합니다. 보드에서 방향키로 이동하고 Enter/Space로 착수할 수도 있습니다.
- **조이패드:** 대국 시작 후 패드의 버튼을 한 번 눌렀다 떼면 연결됩니다. 십자키/왼쪽 스틱으로 칸을 이동하고, 아래쪽 버튼(Xbox A / PlayStation ×)으로 착수합니다. 선택 칸은 노란 테두리로 표시하며 모든 대전 모드에서 사용할 수 있습니다. 설정·무르기·팝업은 기존 마우스/터치/키보드로 조작합니다.
- 브라우저가 `standard`로 인식하는 패드와 Gamepad API가 필요합니다. `localhost` 또는 HTTPS에서 사용하세요. AI 차례·연출·팝업·비활성 창에서는 패드 입력을 막고, 복귀 시 버튼과 스틱을 놓은 뒤 다시 조작합니다.
- 리버시의 모서리에서 4개 이하를 뒤집으면 플레이어 카드에서 잔나비는 사악하게 웃고 웃음 효과음을, 베짱이는 웃는 표정과 휘파람 효과음을 약 2.6초간 보여줍니다. 소리는 Web Audio 합성이며 사운드 설정을 따릅니다. 모서리 여부와 관계없이 한 수에 5개 이상 뒤집으면 웃음·휘파람 반응보다 메롱 장난이 우선하며, 약 1.4초간 상대에게 메롱한 뒤 돌이 뒤집힙니다. 메롱 시작에 짧고 익살스러운 효과음을 한 번 재생합니다. 싱글/로컬은 연출 후 다음 턴 시간을 시작하며 온라인은 서버 시간을 따릅니다.
- 턴 시간은 제한 없음/30초/60초 중 선택합니다. 모든 모드의 기본값은 30초입니다. 0초가 되면 삑 효과음을 한 번 재생하고 **봐준다 / 게임 종료**를 선택합니다. 혼자 놀기는 사용자, 함께 놀기·온라인은 상대가 선택하며, 선택 중에는 착수와 타이머가 멈춥니다. 봐주면 꿀밤 후 보드·점수·차례를 유지하고 시간을 새로 받으며, 게임 종료를 고르면 상대의 승리입니다.
- 리버시는 합법 수가 없으면 자동 패스하며, 양쪽 모두 착수할 수 없으면 빈칸이 남아 있어도 종료합니다.
- 일반 종료 후에는 결과 화면에서 마지막 수를 무를 수 있습니다. 기권·시간 초과 및 온라인에서는 무를 수 없습니다.
- 로컬/싱글은 다른 탭으로 이동하면 시간과 AI가 멈춥니다. 온라인은 서버 시간이 계속 흐르고 연결 해제 후 30초의 복귀 유예를 제공합니다.
- 온라인 새로고침은 같은 탭의 세션으로 복구됩니다. 재대결은 양쪽 동의가 필요합니다. 방 나가기는 방 전체를 종료합니다.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | Vite + 온라인 서버 동시 실행 |
| `npm run dev:web` | 프론트엔드만 실행 |
| `npm run dev:server` | 온라인 서버만 실행 |
| `npm run typecheck` | 프론트엔드 및 서버 타입 검사 |
| `npm test` | 규칙·AI·무르기·타이머·온라인 통합 테스트 |
| `npm run test:watch` | 테스트 감시 모드 |
| `npm run build` | 타입 검사 후 프론트엔드와 서버 빌드 |
| `npm start` | 빌드 결과와 Socket.IO를 단일 서버로 제공 |
| `npm run preview` | 프론트엔드 빌드 미리보기; 온라인 서버는 포함하지 않음 |

## 빌드한 게임 실행

```sh
npm run build
npm start
```

**http://localhost:3001**에서 프론트엔드와 온라인 기능을 함께 제공합니다. 배포 시에는 WebSocket을 지원하는 리버스 프록시와 HTTPS를 연결합니다. 외부 호스팅 배포는 아직 수행하지 않았습니다.

환경 변수는 필수가 아닙니다.

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `PORT` | `3001` | Node.js 서버 포트. 개발 서버에서 변경하면 `vite.config.ts` 프록시도 맞춰야 합니다. |
| `VITE_SERVER_URL` | 현재 origin | 별도 Socket.IO 주소가 필요한 경우 사용. 일반 실행은 같은 origin과 프록시를 권장합니다. |

방과 대국은 단일 서버의 메모리에 보관합니다. 서버를 재시작하면 사라집니다. 다중 서버 배포, 계정, 저장된 대전 기록, 랭킹은 구현하지 않았습니다.

## 구현 구조

```text
shared/game/         게임 타입, 규칙·AI 선택, 상태 복사·돌 집계·공통 종료 처리
shared/games/reversi/ 리버시 규칙, AI 탐색, 보드 크기·좌표
shared/games/gomoku/  오목 규칙·양쪽 3-3/4-4/장목 금수 판정, 5단계 AI 탐색, 보드 크기·좌표
shared/games/chess/   chess.js 기반 체스 규칙, 반복 이력, 5단계 AI 탐색
shared/games/janggi/  장기 행마·장군·빅장·포진, 5단계 AI 탐색
shared/protocol.ts   온라인 메시지 타입과 Zod 입력 검증
src/stores/          Pinia 게임 상태와 무르기 이력
src/composables/     진행 제어, 타이머, 오디오, 리액션, 온라인 연결
src/workers/         게임별 AI를 실행하는 Web Worker와 요청·응답 타입
src/components/     시작 화면, 보드, 플레이어, 대기실, 결과, 공통 UI
src/styles/          글로벌 스타일과 디자인 토큰
server/              서버 권한 판정, 방·세션·시간 관리, 정적 파일 제공
tests/               규칙/스토어/수명 주기/네트워크 테스트
```

`App.vue`는 화면 전환과 모달 우선순위를 관리합니다. 대국 화면은 최대 720px 보드와 오른쪽 대국 정보로 구성하며, 태블릿·모바일에서는 대국 정보를 보드 아래에서 펼쳐 봅니다. 플레이어 영역은 차례가 바뀌어도 높이를 유지합니다. 헤더, 대국 정보, 게임별 진행 정보·팁, 시간초과 선택 내용은 각각 컴포넌트로 분리합니다. AI 대전과 힌트는 `useGameAiWorker`를 함께 사용하며, 계산 취소와 오래된 응답 차단은 이 composable에서 관리합니다. 이력 저장과 Worker 전송은 `snapshotGameState`로 독립된 상태를 복사합니다.

`gameType`은 리버시·오목·체스·장기, `mode`는 혼자·함께·온라인 대전 방식을 나타냅니다. 공통 엔진이 게임 종류에 따라 규칙과 AI를 선택하고, 온라인 서버도 같은 규칙으로 착수와 승패를 검증합니다. `flipped`·점유율 반응은 리버시에만 사용하고 오목은 `winningLine`으로 승리한 줄을 기록합니다. 장기의 쉼은 `passed`로 기록합니다. 온라인 방의 게임은 생성 시 고정되며 재접속·재대결에서도 유지됩니다. 게임 종류가 생략된 기존 설정은 리버시로 처리합니다.

체스·장기는 `pieces`에 종류와 소유자를 저장하고 `board`에는 기존 집계를 위한 소유자 배열을 유지합니다. 내부 `black`/`white`는 선공/후공 식별자로, 체스의 백/흑과 장기의 초/한 표시는 `sideName`에서 변환합니다. 이동은 `shared/game/pieces.ts`에서 출발·도착·승격을 숫자로 인코딩하며, 서버가 게임별 형식과 합법성을 모두 확인합니다. FEN·반복 이력·빅장 상태는 무르기, Worker, 온라인 스냅샷에서 함께 복사합니다.

체스 규칙은 BSD-2-Clause 라이선스의 [chess.js](https://github.com/jhlywa/chess.js)를 사용합니다. 장기 행마는 [대한장기협회 행마법](https://koreajanggi.cafe24.com/business/business3.php)을 참고하되 무승부는 위의 친선 규칙을 따릅니다.

캐릭터와 기물은 직접 작성한 SVG이며, 캐릭터 연출은 CSS 애니메이션을 사용합니다. BGM 3종 및 SFX는 Web Audio로 합성합니다. 외부 이미지·음원 다운로드나 API 키가 필요하지 않습니다. 사운드는 첫 사용자 입력 이후 활성화됩니다.

## 검증과 현재 범위

- Chrome에서 싱글 대국 종료, AI 응답 전후 무르기, 키보드 착수, 로컬 60수 대국 종료를 확인했습니다.
- 두 Chrome 탭에서 온라인 입장·캐릭터 교환·착수 동기화·새로고침 복귀·기권·재대결·방 종료를 확인했습니다.
- Chrome의 390px 시작 화면, 320px 게임 화면에서 가로 넘침 없이 표시되는 것을 확인했습니다.
- 조이패드 연결/해제, 스틱 데드존, 방향 반복, 중복 착수 방지, 입력 잠금과 보드 연동을 가상 패드 자동 테스트로 확인했습니다. 실물 패드의 USB/Bluetooth 연결은 아직 검증하지 않았습니다.
- 실제 iOS Safari의 터치·오디오와 외부 네트워크 환경은 별도 검증이 필요합니다.
- 캐릭터와 엔딩은 SVG/CSS로 만든 초기 연출입니다. 기획의 세밀한 표정·큰절·상호작용 및 녹음된 캐릭터 음성은 추가 아트 작업 대상으로 남겨두었습니다.
