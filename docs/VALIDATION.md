# 초기 구현 검증 기록

검증일: 2026-09-22. Node.js 22.23.1, 로컬 Chrome 환경.

## 자동 검증

`npm test`의 45개 테스트가 통과했다. 다음을 검증한다.

- 초기 배치, 8방향/다방향 뒤집기, 경계 및 빈칸, 불법 착수, 자동 패스, 빈칸이 남은 종료, 무승부, 기권·시간 초과 판정.
- 여러 결정적 수순의 완주와 매 수의 돌 개수/합법 수 불변식.
- AI 합법 수, 코너 평가, 탐색 시간 예산.
- AI 전후 무르기, 사용자 패스로 AI가 여러 번 둔 경우, 인당 무르기 차감, 무르기 한도 및 정상 종료 복원.
- 연속 입력 잠금, 무르기/재시작 뒤 도착한 AI 응답 폐기, 남은 시간 복원, 탭 비활성화/복귀, 화면 이탈 시 작업 정리.
- 온라인 서버 판정, 잘못된 턴/좌표/중복 요청/오래된 상태/무르기 거부, 세션 토큰 복귀, 세 번째 사용자 거부, 동기화된 한 판 완주.
- 온라인 마감 시각의 착수 거부, 연결 종료 중 타이머 유지, 재접속 유예 및 양쪽 이탈 종료, 양쪽 동의 재대결.

`npm run build`의 Vue/서버 타입 검사와 프론트엔드 및 서버 빌드가 통과했다. 빌드된 서버의 HTML, JavaScript 엔트리, `/health` 응답도 확인했다.

## Chrome 실조작

- 시작 화면: 모드, 캐릭터, 턴 제한 선택 및 시작.
- 키보드: D3에서 왼쪽 화살표로 C3, 오른쪽 화살표로 D3 복귀, Enter 착수.
- 싱글: AI 응답 전/후 무르기 후 2:2 초기 상태 복원. 한 판을 끝까지 진행해 흑 0 : 백 44, 빈칸 20개에서 양쪽 착수 불가 종료 확인. 종료 후 무르기로 게임 재개.
- 로컬: 최초 수 무르기로 흑의 남은 횟수만 0이 되는 것을 확인. 별도 대국 60수 완주, 흑 19 : 백 45 종료 확인.
- 온라인: 두 탭 입장, 게스트의 캐릭터 교환, 양쪽 준비, D3/C3 착수 후 양쪽 3:3 점수, 게스트 새로고침 후 같은 상태 복구, 무르기 비활성화 확인.
- 온라인 종료: 기권 결과 양쪽 표시, 한쪽만 재대결 동의 시 대기, 양쪽 동의 시 2:2로 새 게임 시작, 방 나가기 후 상대도 시작 화면으로 이동.
- 화면: 기본 데스크톱, 390px 시작 화면, 320px 보드/조작 메뉴. 작은 폭에서 보드 정사각형 및 가로 넘침 없음.
- 초기 싱글 대국의 브라우저 console error/warn 없음. 이후 개발 중 재로딩 구간에는 `A listener indicated an asynchronous response ... message channel closed` 메시지 3건이 기록되었다. 브라우저 확장의 메시지 채널로 추정되며 발생 주체를 확정하지는 않았다. 위 대국 기능 검증은 통과했다.

- 베짱이 승리 시 바이올린 준비·휘두르기, 잔나비 회전 퇴장, 베짱이 인사로 이어지는 3.2초 연출 후 결과창을 표시한다. 마지막 대량 뒤집기 연출이 있으면 먼저 완료한다.
- 버튼/Escape로 건너뛰기, 동작 줄이기 설정에서 즉시 결과 표시, 컴포넌트 제거 시 효과음·완료 타이머 정리를 적용했다.
- 결과창의 기존 전신 동작을 제거하고 승자의 큰 웃음 얼굴과 어깨를 정지 상태로 표시한다. 무승부는 두 캐릭터를 함께 표시한다.
- 자동 테스트 총 78개 및 타입 검사·빌드 통과. 새 대국에서 재생, 같은 결과 스냅샷의 중복 재생 방지, 잔나비 승리·무승부 제외, 타이머 정리와 건너뛰기를 검증했다.
- Chrome 로컬 기권으로 베짱이 승리 진입, 자동 결과 전환, 결과 재열기, 375px 화면 배치와 건너뛰기를 확인했다. 실기기 Safari iOS는 미검증.

## 잔나비 더블 래리어트 (2026-09-22)

- 승자에 따라 베짱이 바이올린 연출과 잔나비 더블 래리어트 연출을 선택한다. 잔나비는 바나나 대신 양팔을 옆으로 뻗고 세로축을 중심으로 360도 회전하며, 베짱이는 타격 후 회전하며 퇴장한다.
- 잔나비 승리 결과창은 맥주잔을 든 큰 웃음 얼굴 클로즈업으로 표시한다. 무승부나 베짱이 승리에는 맥주잔을 표시하지 않는다.
- Chrome 혼자 놀기에서 베짱이 기권 → 잔나비 연출 → 맥주잔 클로즈업 결과창 전환 확인. 두 승자 각각의 연출 선택·결과·재대국·중복 스냅샷을 자동 검증했으며 전체 테스트 78개와 타입 검사·빌드 통과.

### 잔나비 5회전 연속 타격

- 회전을 5바퀴(1800도)로 늘리고 960/1280/1600/1920/2240ms의 5회 타격에 효과음, 베짱이 반동, 화면 흔들림, 타격 문구를 맞췄다. 다섯 번째 타격 후 베짱이가 날아가며 전체 연출은 3.2초를 유지한다.
- 5회 효과음과 마지막 타격, 건너뛰기 이후 남은 타격 취소 자동 검증 포함 전체 테스트 79개·빌드 통과. Chrome에서 회전 중 세 번째 타격 문구와 반동 표시 확인.
